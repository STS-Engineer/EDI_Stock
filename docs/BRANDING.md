# Identité visuelle

Le logo original AVOCarbon Group est intégré localement dans
`edi_stock/static/avocarbon-logo.png`. Il remplace le symbole générique de
l’en-tête, sans requête vers un site externe au chargement de l’application.
L’aperçu HTML autonome contient les mêmes octets sous forme d’image intégrée.

- Source : en-tête du site officiel https://www.avocarbon.com/
- Fichier officiel : https://www.avocarbon.com/wp-content/uploads/2023/01/logo-avocarbon-1.png
- Récupéré et inspecté visuellement le 5 octobre 2026.
- Format d’origine conservé : PNG transparent, 718 × 132 pixels.
- SHA-256 : `a11f05215397c2ba59980c1f11a92a402b5c5d772504e3f3a9740c0c1426b347`.

Les couleurs et les proportions de l’image n’ont pas été modifiées. Le fond
blanc de son conteneur assure la lisibilité sur l’en-tête sombre. Le logo est
réduit proportionnellement sur mobile et porte le texte alternatif
« AVOCarbon Group ».
